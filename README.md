# To-Do App

## Overview

A simple and interactive To-Do application built using HTML, CSS, and JavaScript.

This project allows users to add multiple tasks, delete existing tasks, and receive custom notifications for invalid actions. It was created to practice DOM manipulation, event handling, functions, arrays, and JavaScript fundamentals.

## Features

* Add multiple tasks at once
* Delete existing tasks
* Custom notification system
* Input validation
* Dynamic DOM manipulation
* Responsive user interface
* Modern dark theme design

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How It Works

### Add Tasks

Enter one or more tasks separated by commas:

```text
Learn HTML, Learn CSS, Build Project
```

Click **Add Tasks** and each task will be added to the task list.

### Delete Tasks

Enter one or more task names separated by commas:

```text
Learn HTML
```

Click **Delete Tasks** and matching tasks will be removed from the list.

### Notifications

The application displays custom notifications when:

* The input field is empty
* Invalid actions are attempted
